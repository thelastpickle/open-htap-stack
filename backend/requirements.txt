# The SQL engine for the cqlite path.  This pin and the datafusion and
# datafusion-ffi pins the reader was compiled against are one pin, not three:
# the reader hands this library a capsule holding a repr(C) struct, and the two
# sides must agree on its layout.  The cqlite_datafusion wheel beside it is a
# prebuilt artefact in dist/, so no `--locked` build holds the other two now;
# dist/VENDOR.md carries the pin and names the commit the wheel came from.
#
# This line is the binding side of the three.  The Rust crates are published at
# 55.0.0, which carries arrow 59; this wheel is published only to 54.0.0.  So 54 is
# the highest the Rust side may take, and DataFusion 55 waits on PyPI rather than on
# anything in this repository.  Raise all three together or none of them.
datafusion==54.0.0
